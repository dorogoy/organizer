- (event) TYPEFACE ANALYSIS — the two candidates are strong for OPPOSITE reasons, which is the shape of the decision. LEXEND was designed to reduce visual stress and raise reading proficiency; wide apertures, generous spacing. Its argument here is the USER'S COGNITIVE STATE — the protagonist reads at 21:50 depleted and overwhelmed, which is precisely the condition Lexend was built for. Caveat worth knowing: Lexend's core superpower is SUSTAINED PROSE reading, and this app has almost no prose — single-line task labels — so part of its advantage is unused. LORA's argument is SYSTEM COHERENCE: Sergio's iconography is printed-matter (misregistered riso offset), and a serif IS printed-matter typography, so Lora ties the type to the drawing language in a way a sans cannot. Lora's risk is register on Android, where a serif reads as editorial or content-app, and serif UI furniture ('Hecho', 'Otra mas facil / Ahora no') reads editorial or luxury rather than utilitarian.
